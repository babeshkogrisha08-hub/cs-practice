git это инструмент для создания версий

github это веб приложение для хранения коммитов и репозиториев

при слиянии веток происходит перенос данных в одну ветку

git status — Показывает текущее состояние. Выводит список измененных, новых (неотслеживаемых) и подготовленных к коммиту файлов, а также название текущей ветки.



git diff — Показывает неподготовленные изменения. Сравнивает состояние файлов в вашем рабочем каталоге с индексом (staging area). Показывает конкретные строки, которые вы изменили, но еще не добавили через git add.



git diff --staged (или --cached) — Показывает подготовленные изменения. Сравнивает файлы, уже добавленные в индекс (git add), с последним коммитом (HEAD). Показывает то, что именно войдет в ваш следующий коммит.

git diff — показывает разницу (изменения) между файлами, коммитами или ветками.



git show — показывает детали и изменения одного конкретного коммита.



git log — показывает историю (список) всех коммитов.



git log -S "<текст>" — находит коммиты, где указанный текст был добавлен или удален.



git blame <файл> — показывает построчно, кто и в каком коммите последним менял каждую строку файла.

git revert создаёт новый коммит, который отменяет изменения указанного коммита. История не переписывается.



git reset --hard просто удаляет коммиты из истории и сбрасывает все несохранённые изменения.



Почему revert безопаснее для опубликованной истории:

Не ломает работу другим: git reset --hard переписывает историю. Если отправлять такие изменения на сервер (git push --force), у других разработчиков возникнут конфликты и сбои при обновлении их локальных веток.



Проще отследить: git revert оставляет прозрачный след в истории — видно, что именно, когда и зачем было отменено.



Безопасно для данных: При git reset --hard незакоммиченные изменения и удалённые коммиты можно легко потерять навсегда.
